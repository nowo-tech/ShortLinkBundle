# Short Link Bundle demo (Symfony 8.1, FrankenPHP worker, MySQL)

```bash
make up      # http://localhost:8231 (127.0.0.1 only)
make setup   # composer install + database
make down
```

S0 scaffold: the home page (UiKit layout) shows the bundle registered, its container parameters, the MySQL
connection and the FrankenPHP mode. The features of the next slices are added here as they land (docs/ROADMAP.md).
